# Working agreement

This is a personal LeetCode practice repo. The point is for the user to solve
the problems themselves.

**Do not write or complete solution code unless explicitly asked.** No filling in
function bodies, no "here's the implementation", no suggesting the algorithm
unprompted. The user will ask if they want help.

When asked for help, prefer the smallest useful thing: answer the specific
question, point at the line, name the concept. Don't hand over a full solution
unless that's what was requested.
